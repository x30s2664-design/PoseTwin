# PoseTwin v7 — 15-Segment Teaching Mannequin

本版將原本的「骨架」改為 **15 節段教學人體模型**，供學生直接對照模仿。

## 15 節段
1. 頭頸部 × 1
2. 上軀幹 / 胸廓 × 1
3. 下軀幹 / 骨盆 × 1
4. 左 / 右上臂 × 2
5. 左 / 右前臂 × 2
6. 左 / 右手部 × 2
7. 左 / 右大腿 × 2
8. 左 / 右小腿 × 2
9. 左 / 右腳部 × 2

合計 15 節段。

## 視覺設計
- 中央節段：中性淺色
- 左側肢體：藍色
- 右側肢體：橘色
- 關節點預設隱藏，只保留除錯開關
- 所有節段都有體積，不再以細骨棒作為主要顯示
- 上、下軀幹分離，能更清楚呈現彎腰、側傾與轉身

## 教學功能
- 鏡像模仿
- 0.25× / 0.5× / 0.75× / 1×
- 前一格 / 後一格
- 正面 / 側面視角
- 動作殘影
- 固定骨長
- EMA 平滑
- 腳底貼地
- 有限 Root 位移
- 處理格
- 前 / 後鏡頭
- WebM 錄影與 PNG 截圖

## 使用建議
全身模式下，讓頭頂、雙手、雙腳都留在畫面內，人物約佔畫面高度 75–85%，可提高 15 節段人偶的穩定性。
